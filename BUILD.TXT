COMPILATION DEPENDENCIES
------------------------
To compile this project, the host operating system must provide:
1. A C compiler (cc / clang / gcc)
2. Standard C runtime headers (glibc, musl, BSD libc, ucrt in Windows)
3. SDL2 Development Libraries and the 'sdl2-config' build utility

DEPENDENCY INSTALLATION (DEBIAN / LINUX MINT / UBUNTU)
------------------------------------------------------
Initialize your system's package management engine and install the universal 
compilation utilities alongside the SDL2 core development frameworks:

   sudo apt update
   sudo apt install build-essential libsdl2-dev clang

   Note: clang is optional, but available in case you want to use it.

DEPENDENCY INSTALLATION (ARCH LINUX)
------------------------------------
Synchronize your system's rolling-release core packages and deploy the native 
base-devel toolkit alongside the system SDL2 tracking library:

   sudo pacman -Syu
   sudo pacman -S base-devel sdl2 clang

   Note: clang is optional, but available in case you want to use it.

DEPENDENCY INSTALLATION (FREEBSD)
---------------------------------
Synchronize the native package management database and pull down the system 
SDL2 framework layers. The baseline Clang compiler is already built natively 
into the FreeBSD base operating system layer:

  sudo pkg update
  sudo pkg install sdl2

BUILD INSTRUCTIONS (UNIX-LIKE SYSTEMS)
-------------------------------------------------
1. Open your terminal environment inside the root project 
   directory.
2. Initialize and grant execution permissions to the configuration script:
   
   chmod +x ./configure

3. Run the silent configuration script to probe local system headers, locate 
   the system compiler, and dynamically write the local Makefile:

   ./configure

4. Execute the build automation engine to compile the final binary target:

   make

5. To wipe compiled binary targets and restore the source tree to a clean slate:

   make clean

BUILD INSTRUCTIONS (WINDOWS VIA MSYS2 ENVIRONMENT)
--------------------------------------------------
1. Download and initialize the MSYS2 environment subsystem.

2. Select your preferred environment profile and deploy the corresponding 
   package toolchains via the pacman subsystem:

   OPTION A: PURE LLVM / CLANG STACK
   - Launch the "CLANG64" terminal profile environment window.
   - Synchronize and install the LLVM tools and native SDL2 libraries:
     
     pacman -Syu
     pacman -S mingw-w64-clang-x86_64-toolchain mingw-w64-clang-x86_64-sdl2

   OPTION B: TRADITIONAL GNU / GCC STACK
   - Launch the "UCRT64" terminal profile environment window.
   - Synchronize and install the GNU tools and native SDL2 libraries:
     
     pacman -Syu
     pacman -S mingw-w64-x86_64-toolchain mingw-w64-x86_64-sdl2

3. Execute the standard POSIX shell commands inside your project path:

   ./configure
   make

   The configuration engine will automatically append the native '.exe' file 
   extension to output a clean, standalone 64-bit Windows binary.
