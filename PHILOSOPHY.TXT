                       VERNICHTUNG PHILOSOPHY GUIDE
===============================================================================

WHAT IS THE GOAL?
-----------------
Vernichtung exists to be a completely independent, reconstruction
of the id Tech 1 architecture under a permissive, non-viral license.
And to fulfill John Carmack's and other devs wishes.

"The recent discussions around copilot are a good opportunity to say 
this: I wish I could have licensed the Id source code releases as BSD. 
The GPL virality wound up being a net negative, and more value would 
have come from BSD. My partners would never have gone for it, though."
- John Carmack, 7/6/2021

If you know ReactOS, you know what is goal of Vernichtung then (but not out of hate.)

THE CLEAN-ROOM STANDARD
-----------------------
Unlike other source ports (like Chocolate Doom or any source port) that edit 
the original id source tree, Vernichtung is built 
completely from scratch.
No, we dont say we hate these sources ports

We only use public specs and WAD documentation to reconstruct the engine. 
Because there is no original code here, we can legally use a fully 
permissive license.

LICENSING & EXCEPTION
---------------------------
This engine is officially released under the 3-Clause BSD License. 

We do not accept viral copyleft code into the Vernichtung because we 
want to keep this project completely permissive. 

But wait, there is an exception for two licenses: LGPL-2.1 and MPL-2.0, we dynamic-link them!
No, you cant use LGPL-3.0 as it has Anti-Tivoization rule

LIMIT-REMOVING VANILLA
----------------------
Vernichtung tries to feel exactly like classic 1993-1994 Doom (with the 35Hz 
tick timer, player physics, and classic calculations). 

But we remove the annoying engine limits:
* No Visplane Overflows: We use dynamic heap allocation (malloc) instead 
  of fixed arrays, so the engine won't crash if a map has too many floors.
* Hardened Parsing: We put strict boundary checks on all WAD chunk loaders 
  to protect the heap from crashing if data is jumbled or malformed.
* Basically, Crispy Doom but with Chocolate Doom gameplay and visuals

Why making Vanilla?
----------
Vernichtung is built to be Vanilla DOOM because we want make Vanilla Doom first, 
then other people can add their own featrues to their engine like ZScript or more!

And that is all.
